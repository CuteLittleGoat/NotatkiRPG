# Zgłoszenia problemów z mechanizmem map

Każdy problem ze specyfikacją rysunku, skryptem map (`narzedzia/przygotuj_mape.py`),
podglądem (`narzedzia/podglad_mapy.cjs`), generatorami, przykładowymi rysunkami albo
wyświetlaniem map w aplikacji — osobny plik w tym folderze. Zasady:
[`../README.md`](../README.md), rozdział „Zgłaszanie problemów”.

**Nazwa pliku:** `RRRR-MM-DD_Krotki_opis_problemu.md` — data zgłoszenia, podkreślnik,
opis bez polskich znaków i spacji (np. `2026-11-15_Arkusz_style_poza_defs_trafial_do_map_graczy.md`).

**Plików nie usuwa się** po naprawie — zostają jako dokumentacja; naprawę opisuje się w
[`../Changelog.md`](../Changelog.md) i w polu „Stan”.

**Bez spoilerów** — repozytorium jest publiczne; przykłady wymyślone, nie z materiału MG.

## Szablon zgłoszenia

```markdown
# Krótki opis problemu

**Zgłoszono:** RRRR-MM-DD
**Dotyczy:** specyfikacja / skrypt map / podgląd / generator / przykład / aplikacja (plik)
**Stan:** otwarty | naprawiony RRRR-MM-DD (Changelog.md, wpis z tą datą)

## Objaw
Co widać (albo czego nie widać). Czy problem zgłasza się sam (błąd, ostrzeżenie), czy
trzeba go szukać — i po czym go poznać.

## Przyczyna
Dlaczego tak się dzieje (jeśli wiadomo).

## Jak odtworzyć
Najmniejszy wymyślony rysunek / manifest / polecenie, przy którym problem występuje.

## Naprawa
Co zmieniono albo co proponuję zmienić; jaki test pilnuje, żeby problem nie wrócił.
```
